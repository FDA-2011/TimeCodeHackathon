# Код Времени

Прототип ИИ-сервиса подготовки новостного дайджеста по кибербезопасности
для хакатона.

## Как запустить

### 1. Установить зависимости

```bash
python -m pip install streamlit requests feedparser pandas scikit-learn sentence-transformers transformers torch python-dateutil
```

Если `torch` не ставится на Windows — установите CPU-версию отдельно:

```bash
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
```

### 2. Запустить

```bash
python -m streamlit run app.py
```

Откроется браузер на `http://localhost:8501`.

### 3. Пользоваться

В сайдбаре:

- выберите период («24 часа до контрольного» или произвольный);
- при необходимости снимите галочку «Использовать Qwen2.5» — тогда сервис
  заработает на keyword-фильтре без скачивания большой модели;
- нажмите **Запустить обработку**.

Результаты появятся в четырёх вкладках: события, журнал, сырые данные, тесты.

## Первый запуск

При первом запуске скачаются две модели:

- `paraphrase-multilingual-MiniLM-L12-v2` (~500 МБ) — для эмбеддингов;
- `Qwen/Qwen2.5-3B-Instruct` (~6 ГБ) — для КБ-фильтра.

Модели кэшируются в `~/.cache/huggingface` и дальше работают офлайн.

Если места на диске мало или интернет медленный — не включайте Qwen,
хватит keyword-фильтра.

## Дополнительные команды

```bash
python main.py              # проверка парсера RSS без интерфейса
python text_summarizer.py   # пример работы суммаризатора
python test_summarizer.py   # тесты суммаризатора
```

## Требования

- Python 3.10 или новее
- Интернет для первого запуска (скачивание моделей)
